## 0.1.0

### New Features

- Docker и Compose в личной Linux VM на helios без прав администратора.
- CLI, установщик, веб-агент и автоостановка на Rust.
- Настройка ресурсов, перенос файлов и TCP-пробросы с сохранением существующей VM.
- HTTPS-шлюз и панель: проекты Compose, логи, управление VM, контейнерами, образами и volumes.
- Тёмная, светлая и системная темы.
- Уведомления о релизах и обновление с проверкой SHA-256, платформы и версии бинарника.

### Bug Fixes

- Панель отвечает сразу и собирает инвентарь в фоне; при ошибке сохраняет предыдущие данные.
- Статистика обновляется независимо от инвентаря.
- PHP-шлюз доступен веб-серверу при строгой umask.

### Documentation

- Инструкции по Compose, ресурсам, очистке и HTTPS.
- Нативная сборка и проверка комплекта релиза.

### Changelog

- Первый выпуск. Используется эмуляция CPU; квоты аккаунта действуют.
- Шлюз поддерживает HTTP API и polling. WebSocket и SSE недоступны.
