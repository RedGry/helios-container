## 0.1.0

Первый публичный выпуск Helios Container: Docker и Compose в личной Linux VM на helios без прав администратора.

### New Features

- Один Rust-бинарник для FreeBSD 14.x amd64: CLI, установщик, веб-агент и автоостановка. Python для работы установленного приложения не нужен.
- Установка QEMU и Alpine Linux в домашний каталог пользователя, настройка Docker и Compose, команд `docker` и `helios-container` и PATH.
- Запуск, остановка, статус и логи VM; автоматический запуск при обращении через `docker` и доступ в Linux через SSH.
- Настройка памяти, диска при установке и до 8 vCPU. Значения по умолчанию: 1 vCPU, 1 ГиБ RAM и растущий диск до 12 ГиБ.
- Перенос файлов через `upload` и `download`, запуск проектов Compose и постоянные данные в volumes.
- Сохраняемые TCP-пробросы с автоматическим выбором свободного порта и доступом через SSH-туннель.
- Опциональный HTTPS-шлюз через университетский PHP-хостинг для портов VM и процессов пользователя на helios.
- Приватная веб-панель: контейнеры, проекты Compose, образы, volumes, порты, логи и управление VM. Просмотр панели не запускает остановленную VM.
- Фоновое обновление инвентаря и независимая статистика; сохранение предыдущих данных при ошибке. Тёмная, светлая и системная темы с запоминанием выбора.
- Автоостановка после 30 минут без обращений к опубликованным портам; возможность отключения для длительных задач. Активные команды защищены от автоостановки.
- Уведомление о новой версии в верхней части панели с просмотром changelog; команды `check-update` и `update`.
- Обновление с проверкой SHA-256, платформы и версии бинарника. Сохраняются диск VM, контейнеры, volumes, SSH-ключи, настройки и пробросы; QEMU и Docker не переустанавливаются.

### Documentation

- Быстрый старт, руководство по VM, Compose, файлам, ресурсам, портам, обновлению, диагностике и очистке; готовый пример nginx + Compose.
- Настройка HTTPS-шлюза и подключения frontend, ограничения HTTP-проксирования.
- Оптимизация Docker-сборок и запуска приложений, кеш, параметры JVM, ожидание готовности API, замеры и рекомендации для профиля 8 vCPU.
- Нативная сборка, правила разработки и релизный скилл. Ветки `feature/`, `bugfix/`, `release/`, PR в `main`, теги `vX.Y.Z`.
- Автоматические проверки Rust, PHP, панели и комплекта FreeBSD в GitHub Actions; автоматическое ревью PR и обновление зависимостей через Dependabot.

### Changelog

- Комплект выпуска: `helios-container-freebsd-amd64`, его `.sha256` и `VERSION`. Описание изменений опубликовано на странице релиза.
- Поддерживается FreeBSD 14.x amd64 и Linux-образы amd64 внутри VM. CPU эмулируется через QEMU TCG; vCPU не резервируют ядра общего сервера, квоты аккаунта сохраняются.
- Bind mounts и пути Compose относятся к Linux VM; для переноса файлов с helios используйте `upload` и `download`.
- HTTPS-шлюз поддерживает HTTP API и polling; WebSocket и SSE недоступны. Авторизацию публичного API обеспечивает приложение пользователя.
