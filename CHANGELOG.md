# Changelog

## Unreleased

## 0.1.0

### New Features

- Docker и Compose в личной Linux VM на helios без прав администратора. Установщик, CLI, веб-агент и автоостановка работают на Rust, установленному kit не нужен Python.
- Настройка CPU, RAM и диска, команды Docker через PATH, перенос файлов и TCP-пробросы. Существующая VM, настройки и ключи сохраняются.
- Опциональный HTTPS-шлюз для контейнеров и процессов пользователя, личная панель по ключу в public_html.
- Группы Compose, управление контейнерами и VM, логи с подсветкой, каталоги образов и volumes с размером и подтверждением удаления.
- Тёмная, светлая и системная темы с сохранением выбора в браузере. Состояние опрашивается каждые 2 секунды, ресурсы собираются отдельно с паузой не менее 5 секунд.
- Уведомления о новых стабильных релизах с описанием изменений. Нативное обновление проверяет SHA-256, платформу и версию бинарника.

### Bug Fixes

- Первый вход в панель получает кэшированный ответ сразу, сбор инвентаря не блокирует страницу. Ошибка сбора сохраняет предыдущие данные.
- Метрики и инвентарь обновляются независимо, устаревший снимок не перезаписывает свежую статистику.
- PHP-шлюз остаётся читаемым веб-сервером при строгой пользовательской umask.

### Documentation

- Русские инструкции по установке, Compose, квотам, очистке, HTTPS и ограничениям хостинга.
- Нативная сборка FreeBSD amd64 и проверяемый комплект релиза без VM, конфигурации и ключей.

### Changelog

- Первый выпуск. Для CPU используется QEMU TCG, квоты аккаунта продолжают действовать.
- Шлюз поддерживает HTTP API и polling. WebSocket и SSE через университетский PHP-хостинг не поддерживаются.
