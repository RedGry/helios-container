# Нативная сборка

CLI, установщик, веб-агент и автоостановка работают из одного Rust-бинарника. PHP обеспечивает HTTPS-доступ через университетский хостинг.

## Сборка

На FreeBSD amd64 нужны Rust, Cargo и C-компилятор:

```sh
sh native/build.sh
```

Готовый бинарник: `native/target/release/helios-container-native`. Установка для пользователей описана в [README](../README.md), проверки и упаковка — в [CONTRIBUTING](../CONTRIBUTING.md).

## Совместимость

Нативный kit использует существующие настройки, диск VM, SSH-ключи, пробросы и ключ панели. Переносить контейнеры вручную не требуется.

Для нестандартного каталога укажите `--base /полный/путь` перед командой. Linux-бинарник для helios не подходит.

Готовый релиз содержит бинарник FreeBSD amd64, SHA-256 и `VERSION`. PHP-шаблон и `.htaccess` включены в бинарник. Старые Python-архивы не поддерживаются нативным обновлением.
